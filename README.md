# BTC Trading Analyzer

BTC 현재가, 실시간 진행 중 봉 차트, 다섯 시간대의 중장기 신호와 과거 유사 사례 기반 예측을 보는 가벼운 Streamlit 대시보드입니다. 실제 주문 기능은 없습니다.

## 인터넷에서 이용하기

공개 배포 진입점은 **`web_app.py`**입니다. [Streamlit 배포 안내](docs/deployment.md)에 따라 배포하면 휴대폰과 PC에서 같은 주소로 접속할 수 있습니다. 이용자의 Python 설치나 거래소 API 키는 필요하지 않습니다.

로컬과 공개 웹 모두 **Binance · BTC/USDT · Live · 일봉 차트**로 고정합니다. 상단에서 BTC·ETH·원/달러 환율·김치프리미엄·나스닥100 선물(NQ)·WTI 원유 선물·미국 10년물/30년물 금리를 봅니다. 거래소와 Demo 모드 선택을 제거했으며 분석에는 Binance 원래 USDT 가격을 사용합니다.

화면은 **시장 개요 / 기술 지표 / 다중 시간대 / 미래 예측** 네 탭입니다. 백테스트·전략 검증·몬테카를로·모의거래·신호 기록·설정 탭과 계좌/전략 설정, 일목 읽는 법 카드, 관찰용 가격 영역과 목표·손절선 표시를 제거했습니다. 앱은 별도 연구 전략이나 모의계좌·신호 기록 DB를 실행하지 않습니다. 기존 로컬 DB 파일은 보존합니다.

**기술 지표**는 추세·RSI·MACD·평균 변동 폭·거래량·일목의 현재 상태를 한국어 카드로 보여줍니다. 시간대를 고르고 RSI/추세 탄력/변동 폭/밴드 폭/거래량을 하나씩 크게 확인하세요. 그래프의 기준선·단위와 손가락/마우스 툴팁으로 값을 읽으며, 다른 이동평균 등의 현재값은 접힌 한국어 표에서 봅니다. 지표 조작은 부분 갱신으로 처리하고 이미 계산한 확정 봉을 재사용합니다.

**시장 개요 → 최근 횡보 흐름**에는 최근 72시간의 반복 횡보 구간만 표시합니다. 자주 상승·하락하거나 크게 움직인 시간의 세 카드를 제거했고 웹의 시간대 집계도 생략합니다. 보조 1시간봉은 지표 준비 이력을 유지하는 260개만 조회합니다.

BTC/ETH가 **약 1분 0.5% 또는 5분 1% 이상** 움직이면 상단에 급등락 카드가 나타납니다. 실제 비교 시간·감지 시각과 최근 코인 관련 소식 최대 2개를 함께 봅니다. 자산·시각·방향이 맞는 이벤트 기사 후보만 연결하며, 원인이 확인되지 않으면 ‘관련 가능’ 또는 ‘원인 확인 중’으로 표시합니다. 페이지를 덮는 팝업은 사용하지 않습니다.

**미래 예측 → 조정은 언제 주의할까요?**에서는 기준 종가 대비 3%·5%·10% 하락을 선택하고, 유사 사례의 첫 도달 구간과 조건부 저점 범위를 봅니다. 현재/과거 RSI·MACD·EMA20과 코인 뉴스도 함께 설명합니다. 미국 주요 경제 발표의 예정 시각·시장 예상치·이전치는 Forex Factory/Fair Economy의 이번 주 공개 자료를 사용하며, 출처 연결/자료 확인이 안 되면 보류합니다. ‘예상 부합·코인에 부담·코인에 우호’ 선택은 발표 결과를 가정한 분홍색 가격 경로입니다. 과거 사례 비중은 미래 확률이 아니며 조정 시점/발표 가정의 예측 정확도는 검증되지 않았습니다.

## 처음 실행하기

Python 3.11 이상을 설치합니다. 개발·검증 환경은 Python 3.12입니다. 터미널에서 프로젝트 폴더로 이동하세요.

### Windows PowerShell

```powershell
cd btc-trading-analyzer
py -3.12 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.lock
Copy-Item .env.example .env
.\.venv\Scripts\python -m streamlit run app.py
```

Python 3.12 대신 3.11을 설치했다면 첫 명령을 `py -3.11 -m venv .venv`로 바꿉니다. 가상환경을 활성화하지 않고도 위 명령으로 실행할 수 있습니다. 설치 오류가 있으면 64비트 Python을 사용하세요.

### macOS / Linux

```bash
cd btc-trading-analyzer
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
cp .env.example .env
.venv/bin/python -m streamlit run app.py
```

`.venv`는 프로젝트 전용 라이브러리 공간입니다. `requirements.lock`은 전체 의존성의 정확한 버전을 고정하며, 설치 시 TLS 인증을 끄지 않습니다. SQLite는 Python 표준 라이브러리를 사용합니다. `.env`에서 선택적으로 공개 캐시 위치 `BTC_WEB_DATA_DIR`와 로그 수준을 설정합니다. `BTC_DB_PATH`는 기존 CLI용입니다.

`uv`를 이미 사용한다면 다음 명령으로 동일하게 설치합니다.

```bash
uv pip sync requirements.lock --python .venv/bin/python
```

패키지 사양은 `pyproject.toml`에서 변경하고, 의존성을 의도적으로 갱신할 때만 다음을 실행합니다.

```bash
uv pip compile requirements-dev.in -o requirements.lock --python .venv/bin/python --python-version 3.11 --universal --no-emit-index-url
uv pip compile pyproject.toml -o requirements.txt --python .venv/bin/python --python-version 3.11 --universal --no-emit-index-url
```

## 대시보드 사용

1. 분석 시장은 Binance BTC/USDT Live입니다. 필요할 때 상단의 데이터 새로고침을 사용합니다. 예전 `BTC_DEFAULT_SOURCE`·`BTC_DEFAULT_EXCHANGE` 환경변수로 Demo나 Upbit 선택을 복구하지 않습니다.
2. 상단은 **BTC·ETH·원/달러 환율·BTC 김치프리미엄·NQ 선물·WTI 원유 선물·미국 10년물/30년물 금리** 여덟 카드입니다. Binance BTC/ETH는 최근 1시간 그래프와 24시간 변화율, 환율·김프는 자료의 시각과 상태를 표시합니다. Yahoo `KRW=X`·`NQ=F`·`CL=F`·`^TNX`·`^TYX`는 공개 스트림을 우선하고 10초 공유 조회를 대체로 사용합니다. WTI는 USD/배럴, 국채는 수익률 %와 변화 %p로 읽습니다. 네 거시 카드는 작은 그래프·원자료 시각·지연 배지를 표시하고 PC에서는 한 줄, 휴대폰/태블릿에서는 두 열로 정렬합니다. 공개 스트림 수신이 무지연 거래소 시세 이용 권한을 뜻하지는 않습니다. 아래 **코인에 영향을 주는 주요 뉴스**에서 코인 수급·규제와 코인에 연결된 유가·전쟁·금리·물가·경제지표 소식의 출처와 영향을 봅니다.
3. **시장 개요**에서 중장기 매수·매도·관망 판단을 봅니다. 차트 시간대는 1시간·4시간·일봉·주봉·월봉이며 간편/상세 보기와 일목균형표·이동평균선·볼린저밴드를 선택합니다. 손가락을 대거나 마우스를 올리면 날짜·가격을 읽고, 손가락을 가로로 움직이면 표시가 따라옵니다. 차트 확대는 끄고 세로 스와이프는 페이지 스크롤로 사용합니다. 진행 중 OHLCV·EMA/밴드는 실시간으로 갱신하며 일목 구름 형상과 종합 신호는 확정 봉 기준입니다.
4. **기술 지표**는 시간대별 RSI·MACD·변동성, **다중 시간대**는 방향·비중·자료 충족 상태를 보여줍니다. 일목은 기본 9/26/52/26봉으로 계산하며 차트와 종합 판단에 계속 반영합니다.
5. **미래 예측**에서 1주·1개월·3개월·6개월 후 **상승·보합·하락**의 도착 가격과 그래프를 함께 비교합니다. 초록은 상승, 회색은 보합, 빨강은 하락이며 유사도 가중 비중이 가장 큰 경로를 굵게 표시합니다. 같은 비중은 공동 우세, 작은 차이는 박빙으로 표시합니다. 가격 계산은 **추세·모멘텀·변동성·거래량·일목** 지표 묶음을 자동 검토하며, 이미 완료된 과거 비교에서 오차가 줄어든 기간에 지표를 고려한 사례/가중치를 반영합니다. 그래프 아래 **예상 가격과 우세 방향의 근거**에서 실제 출발/도착 가격·지표 반영/보류 이유·지표 상태와 유사도·사례 비중/격차·뉴스를 함께 읽습니다. 사례 없는 방향은 비중 0의 점선 가정이며 우세 선정에서 제외합니다. **모델·과거 경로**로 전환하면 기존 파란 기술 모델·주황 과거 재현·보라 뉴스 가정을 봅니다. 뉴스 반영을 끄거나 근거를 펼쳐 비교할 수 있습니다. 가중 비중은 미래 확률이 아니며 방향별 경로·뉴스 가정의 정확도는 아직 검증되지 않았습니다. 과거 검증은 선택된 기술 모델만 평가합니다. 별도 과거 비교·직접 설정·전체 사례 겹치기도 지원합니다. [예측과 과거 유사성 설명](docs/historical-similarity.md)을 참고하세요.

시장 개요 차트 아래 **시장 심리와 월별 흐름**에서 공포·탐욕 지수와 히트맵을 봅니다. Alternative.me의 일별 코인 심리 점수(0~100), 한국어 분류, 전일 변화와 최근 이력을 기준 시각·출처와 함께 표시합니다. **1분마다 최신 값을 자동 확인**하고 원자료 기준 시각과 마지막 확인 시각을 따로 표시합니다. 공급자는 일별로 발표하므로 틱 실시간 점수는 아니며, 조회 실패/오래된 자료는 마지막 값·조회 지연으로 구분합니다. 지수에 검증되지 않은 가격 보정 가중치를 넣지 않습니다.

히트맵은 **연도별 1~12월의 비트코인 등락률**입니다. Binance 월봉의 시가→종가를 사용하며 **전체 이력**을 기본으로, **최근 5년**도 선택할 수 있습니다. 2017년 이후 여러 해와 선택 이력의 월별 평균을 함께 봅니다. 칸을 터치하거나 마우스를 올리면 해당 연도·월의 등락률 또는 평균에 포함된 연도 수를 읽습니다. 휴대폰/좁은 카드에서는 1~6월·7~12월로 나눠 표시합니다. UTC 달력 기준이며 진행 중/누락/잘못된 봉은 평균에서 제외하고, 거래 시작의 2017년 8월 부분월은 *로 표시해 평균에서 제외합니다. 기존 월봉/내용 캐시를 재사용하며 이력 전환이나 칸 선택으로 봉 수집·상위 분석을 다시 실행하지 않습니다.

**주요 지표 발표와 예상치**에는 가까운 미국 CPI/PCE/PPI·고용/ADP/JOLTS·금리/FOMC·GDP/ISM/소매판매/소비자심리 발표 최대 6건을 한국 시각으로 표시합니다. **시장 예상**과 **이전 발표**의 값/단위를 나란히 읽으며 없는 예상치는 미제공입니다. 예측 화면과 같은 Forex Factory/Fair Economy 주간 캘린더·30분 캐시/작업자를 공유하고 화면만 5초마다 확인합니다. 이미 발표된 일정은 예정 목록에서 빠지며 실제 발표값을 이 피드에서 만들어 제공하지 않습니다. 자료원 오류/2시간 넘은 확인값이면 일정/예상치를 보류합니다.

종합 신호는 일봉·주봉·월봉 85%, 단기 봉 15%를 반영합니다. 가격 매력과 하락 진정을 별도로 평가해 단기 상승 전의 눌림목도 검토합니다. 데이터 부족·급락·지지 이탈은 매수를 보류합니다. 점수는 성공 확률이 아니며 예측은 미래 가격을 보장하지 않습니다. [종합 신호 설명](docs/composite-signals.md)에 계산 조건이 있습니다.

가벼운 모바일 화면을 위해 하단 과거 예측 성적·세부 유사도·모든 다운로드를 제거했습니다. 기본 예측과 과거 사례, 검증 부족/가격 유지 가정 대비 열세 안내는 유지합니다. 지표 후보는 최소 12개의 완료된 비교에서 최근 평균 오차가 5% 넘게 작아질 때 반영하고, 부족하거나 악화하면 기본 가격을 유지하며 이유를 표시합니다. 지표 추가만으로 모든 기간의 예측 정확도가 좋아졌다고 주장하지 않습니다.

## 실시간 연결과 갱신

- 브라우저는 Binance 연결 하나로 BTC/ETH `aggTrade`(100ms 주기)와 `ticker`와 BTC 다섯 시간대 공식 `kline`(약 2초 주기)을 함께 구독합니다. 가격은 빠른 체결 메시지에서, 24시간 변화율은 ticker에서 받습니다. 김프용 Upbit BTC는 별도 연결 하나입니다. 숫자와 Canvas 갱신을 최대 50ms씩 합치며 상한은 20회/초입니다. 틱으로 Python 분석을 다시 실행하지 않습니다.
- 시작할 때 Binance BTC/ETH의 최근 60개 분봉을 공개 REST로 받습니다. 이후 현재 틱을 마지막 분의 점에 반영하며 최대 61개 점을 유지합니다. 최근 이력 조회가 실패해도 수신한 가격부터 선을 그립니다.
- BTC/ETH 분봉 요청이 실패하거나 제한되면 자동 재시도합니다. 최근 이력은 같은 브라우저 탭에 잠시 저장해 새로고침에서도 복원합니다. 캐시와 분봉 가격을 실시간 수신으로 표시하지 않습니다.
- WebSocket이 연결되지 않으면 Binance 두 심볼을 한 REST 요청으로 5초마다 조회하고 Upbit는 11초 간격을 유지합니다. 429/418·Retry-After는 대기 시간을 늘립니다. 정상 WS 값은 늦은 REST가 덮어쓰지 않습니다. 15초 이상 갱신되지 않은 값은 **수신 지연 · 마지막 가격**으로 표시합니다. 잘못된 가격·다른 시장·이전 시각 메시지는 반영하지 않습니다.
- 재연결 간격은 1초부터 최대 30초까지 늘어납니다. 숨긴 페이지는 연결을 해제하고 돌아오면 다시 구독합니다. 화면의 분석 탭 전환은 가격 연결을 유지합니다.
- 분석용 확정 봉은 60초마다 확인하며 이미 받은 봉과 계산을 재사용합니다. 수동 새로고침은 해당 시장 자료를 갱신합니다. 현재가 연결과 봉 수집이 독립적이므로 봉 API 오류가 현재가 위젯을 멈추지 않습니다.

다섯 시간대의 진행 중 봉은 기존 Binance 연결로 받아 본 차트에 표시합니다. `지금, 다섯 시간대`에서 현재 봉의 20봉 이동평균선 위치·RSI·MACD·ATR 변동 폭·일목 구름 위치를 함께 확인합니다. 전체 이력의 마지막 EMA/Wilder 상태와 최대 80개의 rolling 초기값만 전송하고 브라우저에서 증분 계산합니다. 같은 봉의 새 수신이 지표의 새 봉으로 누적되지 않습니다. 공식 봉 누락·역순·15초 수신 지연이면 갱신을 보류하고, 다음 서버 동기화 때 확정 자료로 이어 갑니다.

미래 예측의 **초록 점선**은 현재가에서 같은 수익률 경로가 이어진다는 조건부 예상입니다. 선택한 1주·1개월·3개월·6개월, 우세 사례/기본 지표 모델과 뉴스·발표 가정을 현재 가격 기준으로 표시합니다. 기존 종가 기준 경로·방향 비중·과거 사례 재현·검증 성적은 보존합니다. 현재 진행 중 지표는 함께 관찰하며 검증되지 않은 가격 가중치를 임의로 더하지 않습니다. 실시간 경로는 별도로 성능이 검증된 새 예측이 아닙니다. 활성 Plotly 갱신은 최대 0.5초 주기로 합치고 진행 중 갱신은 하나만 유지합니다. 틱별 Python 실행·전체 차트 재생성·추가 분석용 연결/REST/운영 패키지는 없습니다.

원/달러 환율은 Yahoo `KRW=X` 시장 시세를 우선합니다. 3분 넘게 오래된 시장 값은 새 김프 계산에 쓰지 않습니다. 시장 자료를 못 받으면 두나무 은행 고시, Frankfurter ECB 일별 자료 순으로 대체하며 **시장/고시/일별** 출처·시각을 구분합니다. 은행/일별 조회는 60초 간격이고 최근 시장 스트림이 있으면 은행 요청을 미룹니다. 공개 시장 호가도 외환 실행 가격을 보장하지 않습니다. 김프는 `(Upbit BTC/KRW ÷ (Binance BTC/USDT × Coinbase USDT/USD × USD/KRW) − 1) × 100`입니다. USDT를 1달러로 고정하지 않으며 수수료는 제외합니다. 코인·환율·환산 자료가 없거나 지연되면 새 계산을 보류하고 마지막 값은 회색으로 구분합니다.

Yahoo 공개 WebSocket 하나에서 `NQ=F`·`CL=F`·`^TNX`·`^TYX`·`KRW=X`를 구독합니다. 메시지 크기·가격·종목·통화·시각·역순을 검사하고 기존 iframe에서 숫자/작은 그래프만 갱신합니다. 바뀐 값만 그리며 서버의 자동 갱신이나 카드 교체가 최신 스트림 가격을 되돌리지 않게 합니다. 숨긴 페이지와 종료 시 연결·리스너를 해제합니다. 제공 지연/휴장 값은 실시간으로 표시하지 않습니다. NQ/WTI의 무지연 CME/NYMEX 시세에는 별도 권한이 필요하고 ^TNX/^TYX는 국채 가격 자체가 아닌 수익률 지표입니다.

2026-10-06 개발 확인에서는 다섯 종목 REST와 실제 Yahoo 연결/FX 수신이 성공했습니다. 32초 관찰 동안 네 거시 종목의 스트림 메시지는 수신되지 않았으므로 모두 무지연 실시간이라고 확인한 것은 아닙니다. 스트림 자료가 없으면 대체 조회의 마지막 시각과 지연 상태를 표시합니다. 공개 Streamlit에서의 재배포/실제 수신은 별도로 확인해야 합니다.

시세 REST 대체·뉴스는 서버 작업 최대 4개를 공유합니다. 자료원별 진행 중 요청은 하나이며 시세는 10초, 뉴스는 30초 캐시를 사용합니다. 시세 확인은 2초, 뉴스 목록은 10초, 조건부 전망은 15초 fragment로 분리해 코인 연결이나 확정 봉 분석을 재실행하지 않습니다. 오류 시 대기·Retry-After와 마지막 값을 보존합니다. 뉴스 검색과 목록/전망 양쪽에서 **명시적인 코인 연결과 시장 이벤트**가 있는 제목만 선택하며 일반 유가·전쟁·주식 ETF 기사는 제외합니다. 최근 24시간의 한국어·영어 공개 RSS 제목 분류로, 실제 가격 영향이나 기사 원문 검증을 보장하지 않습니다. 급등락 연결에는 정상 확인 2분/발행 30분 이내의 기사만 쓰며 발표 예정·루머·단순 등락 기사는 제외합니다. 조회 간격이 기사 발행 지연을 없애지는 않습니다.

공포·탐욕 지수도 같은 작업자를 공유하며 **60초 조회 캐시**와 오류 대기를 적용합니다. 10초 화면 확인은 API 요청 주기가 아닙니다. 월별 히트맵은 내용 기반 1시간/24개 캐시와 이력 fragment, HTML/CSS를 사용해 새 차트 SDK·iframe·소켓을 추가하지 않습니다. 앞선 개발 환경에서 `api.alternative.me`와 `nfs.faireconomy.media`의 요청은 CONNECT 403이었으나 **2026-10-07 환경 재시작 후 두 실제 자료원 수신/파싱이 성공**했습니다. 확인 시각 19:05 UTC의 공포 지수는 71점·탐욕, 원자료는 같은 날 00:00 UTC입니다. 캘린더에서는 실업수당 청구 예상 200K/이전 197K와 소비자심리 예상 47.5/이전 47.8을 받았습니다. 확인 당시 값이며 미래 값이나 실시간 틱 지수로 주장하지 않습니다. 공개 Streamlit의 실제 재배포/수신은 별도 미확인입니다.

2026-10-07 실제 Binance 요청에서는 2017-08~2026-09의 월봉 110개를 정상 수신했습니다. 첫 부분월을 평균에서 제외했으며, 해당 시점의 월별 표본은 9개 연도(9월은 10개)입니다. Binance 거래 시작 전 Bitcoin 시장 이력을 채우지 않습니다.

Binance REST는 공식 시장 데이터 전용 `data-api.binance.vision`, Upbit REST는 `api.upbit.com`을 사용합니다. 네트워크·지역 제한이 있으면 해당 연결의 실제 오류/지연 상태를 표시합니다. Live 실패를 합성 데이터로 대체하지 않습니다. 서버의 분석 자료 연결과 방문자 브라우저의 현재가 연결은 각각 접근 가능해야 합니다.

## 테스트와 성능


pytest와 배포 검사는 외부 인터넷 없이 계산·캐시 무효화·UI와 공개 진입점을 확인합니다. `scripts/offline_ui_fixture.py`가 검사 프로세스의 공개 자료원 경계에서 응답을 주입하며 제품에 숨은 Demo 모드를 만들지 않습니다. Playwright/Chromium의 `check_live_widget.py`는 거래소 메시지를, `check_live_latency.py`는 수신→DOM 반영 지연·체결 파싱을, `check_macro_stream.py`는 실제 PricingData 형태의 다섯 종목 메시지·단위·원자료 지연·카드 교체·대체/재연결을 확인합니다. `--app-url`은 실제 앱의 임베딩도 확인합니다. `benchmark_macro_updates.py --before-widget <이전 live_prices.py>`는 같은 코인 틱에서 거시 카드의 DOM 변경 횟수를 비교합니다. 응답 주입 검사가 외부 시세의 실제 수신 성공을 뜻하지 않습니다.

`scripts/check_touch_charts.py --app-url <검증 서버> --event-log <이번 실행 계측 로그>`는 390/820/1440px Chromium의 실제 터치 입력으로 가격 조회·가로 이동·세로 스크롤·확대 방지·버튼 터치와 상위 분석 추가 실행 여부를 확인합니다. 물리 기기나 모든 Safari 버전의 검증은 아닙니다. 반복 실행·초기 실행·차트 크기의 비교 조건과 결과는 [성능 기록](docs/performance.md)에 있습니다. 로컬 계산 시간이 실제 호스팅의 전체 접속 시간을 뜻하지는 않습니다.

`scripts/check_direction_forecast.py --app-url <검증 서버> --event-log <이번 실행 계측 로그>`는 세 화면 폭에서 네 예측 기간·세 방향 경로·우세 표시·뉴스/모델 전환·터치와 기존 코인 연결/상위 분석 보존을 확인합니다. 공급자 응답 fixture와 방향 비중 계산 검사는 실증 예측 정확도의 증명이 아닙니다.

`scripts/check_market_insights.py --app-url <검증 서버> --event-log <이번 실행 계측 로그>`는 390/820/1440px에서 최신 일별 지수·월별 전체/5년·발표 예상/이전값·단일 횡보 카드·칸 선택/PC 마우스 상세, 세로 스크롤과 기존 차트/시세 연결·상위 분석 보존을 확인합니다. 공포 지수 32를 포함한 공급자 응답은 검사 fixture이며 현재 실제 지수라고 주장하지 않습니다.

## 문제 해결

- `ModuleNotFoundError` / `ImportError`: 공개 배포의 `main` / `web_app.py`와 설치 로그를 확인합니다. 새 체크아웃은 editable 설치 없이 실행되도록 검사합니다. 수정 반영 후에도 이전 오류가 남으면 Manage app → Reboot app을 사용하세요.
- `403 / 451 / ProxyError`: 해당 호스트의 네트워크·서비스 지역 제한을 확인합니다. 인증서 검증을 끄지 않습니다.
- 시세가 회색으로 표시됨: 마지막 수신 시각을 확인하세요. 연결이 회복되면 자동 갱신합니다. REST만 가능하면 Binance 5초 또는 Upbit 11초 조회로 표시됩니다.
- 데이터 부족: 월봉 EMA200 등 실제 이력이 없는 지표를 채워 넣지 않습니다. 부족한 자료 때문에 신호나 예측을 보류할 수 있습니다.
- SQLite 오류: 기존 파일을 삭제하지 말고 쓰기 권한과 캐시 경로를 확인합니다. 공개 가격 캐시에는 OHLCV만 저장합니다.

`.env`, 키, DB와 로그를 공개 저장소에 올리지 마세요. 이 앱은 공개 데이터만 사용합니다. 작업 단계와 다음 실행의 시작 지점은 [PROGRESS.md](PROGRESS.md)에 기록합니다.
