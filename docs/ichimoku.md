# 일목균형표 계산과 표시

기본 기간은 전환선 9, 기준선 26, 선행스팬 B 52, 표시 이동 26봉입니다. 비트코인은 주말에도 거래되므로 일수가 아닌 선택 시간대의 봉 수로 계산합니다. 지표 설정 JSON의 `ichimoku_conversion`, `ichimoku_base`, `ichimoku_span_b`, `ichimoku_displacement`에 저장하며 이전 설정에 없는 필드는 기본값을 사용합니다.

| 항목 | 계산 | 신호에 쓰는 값 |
|---|---|---|
| 전환선 | 최근 9봉 최고가·최저가의 평균 | 해당 봉에서 계산된 값 |
| 기준선 | 최근 26봉 최고가·최저가의 평균 | 해당 봉에서 계산된 값 |
| 선행스팬 A | 전환선·기준선의 평균 | 현재 계산값과 26봉 전에 계산한 현재 구름 값 |
| 선행스팬 B | 최근 52봉 최고가·최저가의 평균 | 현재 계산값과 26봉 전에 계산한 현재 구름 값 |
| 후행스팬 | 현재 종가를 26봉 과거 위치에 표시 | 현재 종가와 이미 관측된 26봉 전 종가의 비교 |

현재 봉에서 구름 위인지 판단할 때는 **26봉 전의 A/B 계산값**을 사용합니다. 오늘 계산한 A/B를 현재 구름으로 잘못 사용하지 않습니다. 기본 현재 구름 B는 52봉 계산 이력과 26봉 이동으로 연속 78봉이 필요합니다. 월봉 이력이 부족하거나 봉 누락 후 78봉이 쌓이지 않았으면 핵심 지표 대기 상태이며 종합 추천 신호를 보류합니다.

차트는 선행스팬을 26봉 미래 축에 표시합니다. 미래 관측 가격이 아니며 예측 수익·가격을 의미하지 않습니다. 월봉은 실제 달력 월 수로 이동하고 주봉은 주 단위로 이동합니다. 이후 데이터 갭을 넘어 이전 구름을 가짜 확인 근거로 이어 쓰지 않습니다.

후행스팬을 과거 위치에 그리는 처리는 차트에만 있습니다. 분석 테이블에 `close.shift(-26)` 같은 미래 종가를 넣지 않습니다. `ichimoku_chikou_reference`는 이미 확정된 과거 종가이며, 미래 데이터를 추가하거나 바꿔도 이전 봉의 신호 특징은 바뀌지 않습니다. 후행 확인은 전통적 일목의 모든 가격·구름 교차 조건이 아니라 현재 종가와 과거 종가 비교라는 점을 화면에 명시합니다.

화면은 간편 보기에서 구름을 중심으로 보여주고 상세 보기에서 전환선·기준선·후행스팬을 함께 보여줍니다. 구름은 상승·하락 구간을 녹색·붉은색으로 구분합니다. 이동평균선·볼린저밴드·가격 영역을 각각 켜고 끌 수 있습니다. 표시 방식과 사용자가 그린 도형은 분석 입력이나 종합 판단을 바꾸지 않습니다.

독립적인 고가·저가 예제로 계산값·워밍업을 확인하고, 미래 종가 변경·갭 초기화·설정 복원·추세 점수 반영·월봉의 앞/뒤 표시 이동을 검증합니다. 수치와 표시 검증은 거래 정확도나 수익성을 입증하지 않습니다.
