# 국내 NXT 장외 시세 연결

한국투자증권의 실전 Open API 앱키가 필요합니다. 코드는 시세 조회와 인증만 호출하며 주문 API를 호출하지 않습니다.

Streamlit Cloud → 앱 관리 → Settings → Secrets에 아래 두 이름으로 본인의 값을 등록한 뒤 저장하고 앱을 다시 실행합니다. 키를 채팅이나 Git 저장소에 올리지 마세요.

```toml
KIS_APP_KEY = "본인의 실전 앱키"
KIS_APP_SECRET = "본인의 실전 앱시크릿"
```

등록하지 않으면 기존 Yahoo 시세를 계속 사용하며 한국투자 API를 호출하지 않습니다. 서버 환경변수로 같은 이름을 설정해도 됩니다.

평일 NXT 장전(08:00–08:50), 장후(15:40–20:00)에 `NX` 시장의 당일 분봉에서 실제 거래 시각과 가격을 확인합니다. 계좌/API의 NXT 조회 권한과 해당 종목의 NXT 거래 지원이 필요합니다. 휴일·미체결·권한 오류·오래된 자료는 새 시세로 적용하지 않습니다. 마지막으로 검증한 거래는 장 종료 후 마지막 가격으로 유지합니다. 첫 구동이 장 종료 후라면 캐시에 없는 NXT 종가를 만들어내지 않습니다.

수신에 성공하면 가격 옆 상태에 **KIS NXT**가 표시됩니다. 정규장 원자료보다 새로운 거래만 사용하며, 장전·장후 변동률은 정규장 기준가 대비입니다. 가격 표시용 연결이며 기존 과거 차트에 NXT 봉을 임의 합성하지 않습니다. 미국 심야 시세를 제공하는 연결은 아닙니다.

공식 API: [한국투자증권 당일 분봉 조회 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_user/domestic_stock/domestic_stock_functions.py) — `inquire_time_itemchartprice`, `FHKST03010200`, `FID_COND_MRKT_DIV_CODE=NX`.

개발 환경에서는 계정 키 없이 요청 형식·응답 검증·토큰 재사용을 검사했습니다. 실제 계정의 인증·NXT 수신은 키 등록 후 배포 환경에서 확인해야 합니다. 현재 개발 환경은 한국투자 API 호스트의 접속도 제한됩니다.
