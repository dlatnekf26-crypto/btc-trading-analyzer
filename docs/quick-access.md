# 내 종목 빠르게 열기

- 차트를 열고 **☆ 관심종목에 추가**를 누르면 메인 화면의 **내 관심종목**에 저장됩니다. 최대12개이며 **편집**에서 삭제할 수 있습니다.
- **최근 본 종목**은 최근6개를 기억합니다. 관심종목과 겹치는 항목은 중복 표시하지 않습니다.
- 저장한 이름을 누르면 기존 차트·분석 창으로 바로 이동합니다. 별도의 시세 연결이나 이력 다운로드를 추가하지 않습니다.
- 검색은 이름·티커·초성을 지원합니다. `삼전`, `ㅅㅅ`, `마소`, `nvidia`, `005930`처럼 찾을 수 있습니다.
- 공포·탐욕·환율·김치프리미엄은 **시장 참고지표**를 펼쳐서 확인합니다. 접어두면 첫 화면에서 종목 목록을 더 빨리 볼 수 있습니다.

목록은 이 브라우저의 저장 공간에만 보관합니다. 계정 간 동기화는 없으며 사이트 데이터를 지우면 초기화됩니다. 저장 공간이 차단된 경우에는 안내가 표시되고 현재 화면에서만 사용할 수 있습니다. 공개 시장 가격이나 예측 결과를 저장된 최신 시세로 간주하지 않습니다.
